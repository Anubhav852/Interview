# Loom script (about 5 minutes)
1. Problem: students need to book, interviewers need control, the team needs visibility.
2. Design notes tab: derived state, the state table, why nothing is stored.
3. Student: Ananya books a slot, sees the join window and calendar download. Turn on Demo mode.
4. Interviewer: daily schedule, record Pass with rubric, then a Fail with focus areas. Show no-show.
5. Student again: result, feedback, history, leaderboard, cooldown lock on Book tab.
6. Team: filters, nudge, reassign, flag malpractice then reinstate, audit log.
7. Edge cases: day off cancels bookings with no attempt used; double booking guarded by unique index.
8. Assumptions and next steps: real backend using docs/schema.sql, email and WhatsApp alerts.
