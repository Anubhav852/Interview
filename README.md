# GRIT Layover: interview scheduling prototype
Run: open index.html (double-click, or `start index.html`). Data is kept in browser localStorage; "Reset data" restores the seed.
Files: index.html (base app), extras.js (extra features), docs/ (write-up, schema.sql, Loom script).
Tip: switch on Demo mode to record outcomes before a slot's start time.
